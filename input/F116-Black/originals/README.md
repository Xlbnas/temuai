# Placeholder Original Images

This directory contains **placeholder sample images** for development and testing only.
These are NOT real product photos.

For production use, replace these files with real product photography:
- `front.jpg` / `front.png`
- `back.jpg` / `back.png`
- `pocket.jpg` / `pocket.png`
- `fabric.jpg` / `fabric.png`

The TEMU Image Factory pipeline reads `product.yaml` to locate the actual images.
Original directories are always treated as read-only by the application.
